# Java Core — exercícios de algoritmos

Coleção de exercícios de Java desenvolvidos em sala de aula, organizada por tarefas. Cada arquivo contém um programa pequeno para praticar um conceito de lógica ou de linguagem.

**Projeto desenvolvido para fins educacionais.**

## Conteúdo

As pastas <code>tarefa01</code>, <code>tarefa03</code>, <code>tarefa04</code>, <code>tarefa05</code>, <code>tarefa06</code>, <code>tarefa11</code>, <code>tarefa12</code> e <code>tarefa13</code> reúnem exercícios independentes. Há exemplos de entrada com <code>Scanner</code>, operações aritméticas, condições e métodos. Os enunciados estão nos comentários de cada arquivo.

O repositório não usa Maven ou Gradle. Os exercícios não formam uma aplicação única.

## Como executar um exercício

Instale um JDK e, a partir da raiz do clone, compile e execute o arquivo escolhido. Por exemplo:

~~~bash
git clone https://github.com/Rafael-M-Silva/Java-Core.git
cd Java-Core
javac tarefa01/Exercicio01.java
java tarefa01.Exercicio01
~~~

O exercício acima lê um número e mostra seu sucessor. Para outro exercício, substitua a pasta e o nome da classe nos dois comandos. Alguns programas solicitam dados no terminal.

## Aprendizados

A coleção registra a prática de leitura de entrada, decomposição em métodos, decisões e resolução gradual de problemas. Como material de aula, alguns arquivos podem conter tentativas e abordagens próprias do processo de aprendizagem.
